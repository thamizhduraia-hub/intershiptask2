# Sales Data Cleaning using Python

## Project Overview
This project demonstrates data cleaning and preprocessing using Python and the Pandas library. The dataset was downloaded from Kaggle and analyzed to ensure data quality before further analysis.

## Tools Used
- Python
- Pandas
- Visual Studio Code

## Data Cleaning Steps
- Loaded the CSV dataset using Pandas.
- Displayed the first 5 rows of the dataset.
- Checked dataset information and data types.
- Verified missing (null) values.
- Checked for duplicate records.
- Standardized column names.
- Converted the `Sale_Date` column to datetime format.
- Saved the cleaned dataset as a new CSV file.

## Results
- Missing Values: 0
- Duplicate Rows: 0
- Column names standardized.
- Date column converted to datetime format.
- Cleaned dataset exported successfully.

## Files
- `sales_data-selected-columns.csv` – Original dataset
- `clean_data.py` – Python script for data cleaning
- `cleaned_sales_data.csv` – Cleaned dataset
